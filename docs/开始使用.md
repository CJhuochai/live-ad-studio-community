# 直播投流工作台 2.2.2

**Windows 11 x64，免安装：完整解压后双击 LiveAdStudio.exe。** 不要在微信或ZIP预览里直接运行。已经自带.NET运行时；电脑仍需安装Microsoft Edge WebView2 Runtime。缺少时工具会引导打开[微软官方页面](https://developer.microsoft.com/microsoft-edge/webview2/)。

## 今晚怎么用

1. 点“新场次”或选择对应场次。进入“设置”，填实际账号、日期、后台当前目标、日预算及能接受的试错投入。日预算只限制预算，不保证会花完。
2. 点“目标”，填计划ID、最多接受多少广告费，以及按“支付订单”还是“未退款订单”计算。多款轮讲选“多商品”；商品结构不清楚可以留空，不会硬套某个单品的参考值。固定经营要求写在“固定经营约束”，AI每轮都会收到。
3. 到“诊断与建议”点“填写投放核查”。填实际直播和计划开启时间，检查审核、余额、账户、素材、定向和互斥；不知道就保留“未知”。当前下播后的暂停不能代表直播时没有投放。
4. 点“手动记一笔”，记录后台**同一统计范围的累计值**。OCR只能提供候选，必须对照截图确认。每隔一段时间补一笔；建议调整前后都保留快照。
5. 点“连接ChatGPT”，在官方页面用自己的账号授权，再选择可用模型。可粘贴/拖入截图，也可选择区域并勾选采集授权开始盯盘。后台数据区要保持可见，锁屏或显示器布局变化会暂停。
6. 做过调整后，到“行动与复查”记录实际执行时间、期待变化、停止追加的条件及同期其他变化。满足观察窗和前后各两条有效快照后才能复查；完成后记录锁定，后续改动新建行动。

## 素材和Excel

- “数据与复盘”：导入来客成交明细、增量价值报表。订单按订单号更新，按账号、下单时间范围及直播渠道统计；退款、核销应持续补导。跨零点要在设置中填写完整统计起止。
- “素材体检”：导入本地推导出的“视频”或“图文”效果XLSX。文件通常没有计划ID/报告日期，必须本人核对导出的计划和时间。确认错误范围会影响分析。
- 同计划、同范围、同素材类型取最新导入批次；视频和图文可合并观察，总消耗不能保证与面板完全一致。相同文件再次导入不会重复累计；早期批次留在记录中，最多40批，超过后新建场次。
- 素材相关性需要本人看实际内容再确认。标记“已排除/已停用”只是记录你在后台做过的事，工具不会实际删除视频或暂停投放。零消耗、缺失标题、Invalid Date均不能单独证明素材无效；报表未提供审核/曝光时不会编造。

## ROI与成本

1200÷200＝6只说明：同口径成交1200、广告消耗200时，支付ROI为6。系统不会逐单固定扣200，也不保证该目标能起量。多商品混卖不能以其中一款的价格代替整场成交结构。

若最多接受的是“未退款订单200元”，预估最终保留率80%，换算支付订单成本要求为160元；1200单品参考ROI为7.5。保留率是假设；未知留空，不由一两笔成交自动估计。

ROI试算只显示不同目标下的成本代价，不会修改后台目标。当前目标低于你填写的成本要求时会提醒；实际低消耗先核查资格和素材，不能直接归因为ROI设置过高。自动出价也不保证在可接受成本内成交。

## AI用量、复制和数据

- “AI用量”显示本工具的请求次数、成功/失败，以及接口实际返回的Token数；**不是ChatGPT套餐剩余额度查询**，没有返回的用量显示未知，不估算扣费。授权及额度以官方页面为准。
- 自动分析仅在达到间隔且观察到变化时触发。OCR关键数字可读时按候选数字判断变化，否则按截图像素变化。候选不自动写入财务账本。请求达到本场上限后，已运行的盯盘继续本地采集，不再上传自动分析。
- “复制分析摘要”会复制经营要求、最新指标、关键商品汇总、最近12条可用快照、最近调整和未复查行动，方便交给外部AI深度分析。结构化订单号、消费者UID、券码不进入摘要；自由备注可能含个人信息，分享前检查。
- 数据保存在本机 `%LOCALAPPDATA%\LiveAdStudio`。备份ZIP含订单记录与对话图片，应私下保管；不包含OAuth凭据。
- 换电脑：复制本发布ZIP，解压运行，再在官方页面重新授权。需要转移数据时用“行动与复查”里的“备份工作区/恢复”，不要复制登录凭据。

## 从2.0升级及回退

先退出旧版，建议先在旧版备份完整工作区。新版沿用同一数据目录，首次读取v2工作区会在该目录保留 `before-v21-时间.json`，再升级为v3；不覆盖原来的2.0发布文件。

2.0不能直接读取新版v3。需要回退时退出两版，先另存当前整个数据目录；用升级前的v2完整备份在2.0恢复。自动保留的v2 JSON也可在停用程序后恢复为workspace.json，但图片仍依赖原数据目录，不能只拷贝JSON到别的电脑。不要用旧版覆盖新版数据。

## 能力边界

本版实现可解释的计算、证据诊断和人工复查，不能证明广告增量因果，也不保证起量、盈利、退款率或平台赔付。没有接入本地推自动改价/开关计划；所有实际广告操作由你执行。

AI当前未启用联网搜索；内置资料是核验过的静态版本。官方规则在“规则与来源”可查，功能、保障与资格以你当前后台条款为准。目标电脑的授权、采集和真实直播效果仍需现场试用验证。

## 在线更新
新版可从匿名下载源获取时，右上角显示「更新并重启」。暂停盯盘后点击即可。程序先校验下载包，再备份工作区到本地的 before-update.zip。更新失败时可检查原文件以及程序旁的 .previous 备份。
